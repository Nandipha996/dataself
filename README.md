# DataSelf — Personal Intelligence System

A personal data-driven intelligence platform that helps you reflect, learn, and plan your next move.

## Core Modules
- ETL – capture and store daily reflections
- Journey Check  – personalized recommendations for next best actions
- Analytics – trend and insight generation
- Streamlit App – clean UI to interact with your data

Run locally:
```bash
python3 src/etl/append_daily_template.py
streamlit run app/streamlit_app.py
```
